# Визитка команды глазами жюри

Первая работа в портфолио — сама визитка. Жюри может оценить результат прямо на странице, но связать его с конкретным участником сложнее. В README у аналитика указан процесс («проверяет README»), а у фронтенд-разработчика — область работы («Frontend-разработка»).

Перед сдачей стоит привязать к каждой роли один результат и ссылку на соответствующий коммит. Тогда на вопрос «что сделал каждый?» можно будет ответить по одной таблице.
