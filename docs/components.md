# Компоненты для сайта-визитки

По этой ведомости дизайнер подбирает аналоги из готовой библиотеки и собирает [макет страницы](screens.md). В таблице указано назначение элемента, чтобы можно было сопоставить его с компонентом под другим именем в дизайн-системе.

| Что подобрать | Где и чем заполнить | Какие варианты показать |
| --- | --- | --- |
| Шапка с блоком идентификации | Эмблема, текстовое название команды, девиз, меню и языки | Широкая компоновка и перенос текста на телефоне. Если эмблема дублирует название рядом, для чтения с экрана достаточно текстового названия. |
| Якорное меню | Пять текстовых ссылок по заголовкам разделов | Обычная ссылка, наведение, видимый фокус. На телефоне ссылки переносятся целиком, остаются видны и доступны с клавиатуры. |
| Переключатель языка | Две ссылки RU и EN. Доступное имя группы «Язык страницы / Page language», ссылок — «Русский» и «English» | Выбран RU, выбран EN, фокус на соседнем языке. Выбор читается в обеих темах и сообщается программе экранного доступа. |
| Заголовок секции и основной текст | Заголовки одного уровня для пяти секций, абзацы для рассказа о команде, заголовок ниже уровнем для имени и названия проекта | Однострочный и многострочный заголовки, длинный абзац на узком экране |
| Карточка участника с аватаром | Имя, роль, группа, список навыков, контактная ссылка. Фото и графический аватар занимают одно место. | Фото / аватар, короткое / длинное имя, несколько строк меток, личный контакт / «Связаться с капитаном / Contact the captain» |
| Группа меток | В карточке — навыки участника. В секции навыков — подпись категории и набор меток. | Одна и несколько строк. Метки читаются как текст, без поведения кнопки. |
| Карточка проекта | Заголовок, описание, текстовая пометка типа и ссылка при наличии адреса | «Проект / Project» со ссылкой «Открыть проект / View project» и без неё. «Идея / Idea» с описанием. Тип различим по тексту в обеих темах. |
| Контактная и внешняя ссылка | В карточках и подвале. Для подвала — «Написать капитану / Contact the captain» и «Репозиторий / Repository». | Обычная, наведение и клавиатурный фокус. Для повторяющихся ссылок доступное имя уточняет адресата или название проекта. |
| Подвал | Заголовок «Контакты / Contact» и две ссылки | Ссылки в ряд при достаточной ширине и в столбец на телефоне |

Для страницы со статическим содержимым основные состояния определяются доступными данными. Участник без фото получает аватар. Если выполненных работ пока нет, команда предоставляет идею. Необязательная ссылка занимает место только при наличии адреса. Перед публикацией для каждой карточки нужен реальный текст, для фото и персональных контактов — необходимые согласия.

При передаче указать имена компонентов и вариантов в библиотеке, стили текста и токены отступов, фона, текста и фокуса для светлой и тёмной тем. Общие правила проекта собраны в [дизайн-системе](design-system.md).
