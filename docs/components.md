# Компоненты визитки

| Компонент | Содержимое и состояния |
| --- | --- |
| Шапка | Эмблема со ссылкой на текущую языковую версию, меню, RU и EN. Активная ссылка имеет доступное состояние и контрастную заливку. |
| Первый экран | Событие, название команды, девиз, ссылка к участникам. В центре вращается декоративная сфера. Локализованные подписи на её поверхности задаёт [список в TypeScript](../frontend/data/sphere-labels.ts). |
| Карточка участника | Локализованные имя, роль, вклад и навыки, учебная группа, фото или инициалы. При заполненном личном контакте показывает личную ссылку, иначе ведёт в общий канал с подписью «Через команду / Via the team». |
| Строка навыков | Название категории и список элементов, допускающий перенос. |
| Карточка проекта | Локализованное изображение с альтернативным текстом, тип «Проект / Project» или «Идея / Idea», название, описание и необязательная ссылка-кнопка. Для Dobropay обложка дополнена фирменным знаком и написанием `dobropay`. |
| Подвал | Канал связи команды и отдельная ссылка на репозиторий. |

Тексты и адреса хранятся в [данных команды](../frontend/data/team.ts), отображение профиля — в [компоненте карточки](../frontend/components/member-card.tsx). Общие стили и состояния описаны в [дизайн-системе](design-system.md).
