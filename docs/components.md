# Компоненты визитки

| Компонент | Содержимое и состояния |
| --- | --- |
| Шапка | Эмблема со ссылкой на текущую языковую версию, меню, RU и EN. Активная ссылка имеет доступное состояние и контрастную заливку. |
| Первый экран | Событие, название команды, девиз, ссылка к участникам. Справа вращается сфера. Перетаскивание поворачивает её, движение указателя раздвигает частицы, а прокрутка расширяет оболочку. На её поверхности по очереди появляются до трёх подписей из [навыков команды](../frontend/data/team.ts). |
| Карточка участника | Имя, роли, достижения, учебная группа, фото или инициалы. Роли и теги навыков указаны на английском. Теги выровнены по нижнему краю карточки с внутренним отступом. |
| Строка навыков | Название категории и список элементов, допускающий перенос. |
| Карточка проекта | Тип, название, краткое описание и отдельная ссылка на репозиторий при наличии. Кнопка «Подробнее / Read more» раскрывает снимок главной страницы и описание реализованных технических решений. Повторное нажатие сворачивает карточку. |
| Подвал | Канал связи команды и отдельная ссылка на репозиторий. |

Тексты и адреса хранятся в [данных команды](../frontend/data/team.ts), отображение профиля — в [компоненте карточки](../frontend/components/member-card.tsx). Общие стили и состояния описаны в [дизайн-системе](design-system.md).
