# 0030. Доступ разработчика по SSH

Дата принятия — 2026-11-26.

**Контекст.** Владельцу нужен отдельный вход на сервер с локальным ключом, защищённым пассфразой.

**Решение.** Выделить пользователя dev с обычными правами и разрешить для него только аутентификацию по открытому ключу. Закрытый ключ Ed25519 хранится в ~/.ssh, а сведения для входа — в локальном файле документации с правами 0600, исключённом из Git.

**Последствия.** Пассфразу обрабатывает SSH-клиент на рабочей машине. Администратор может отозвать доступ, удалив открытый ключ из authorized_keys. [Конфигурация и подключение](../../infra/production/README.md)
