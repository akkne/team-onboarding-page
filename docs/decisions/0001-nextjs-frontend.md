# 0001. Интерфейс Team Onboarding на Next.js

Дата принятия — 2026-11-25.

**Контекст.** Команде нужна запускаемая основа проекта с русской и английской версиями интерфейса.

**Решение.** Разместить приложение Next.js App Router в `frontend/` и использовать предусмотренные шаблоном TypeScript и Tailwind CSS. Язык стартовой страницы задаёт маршрут.

**Последствия.** У каждой версии страницы есть постоянный адрес. Разработчик запускает приложение через npm или Docker Compose. Сборка и проверки типов выполняются из `frontend/`.
