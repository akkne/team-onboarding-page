# 0012. Технологические навыки команды

Дата принятия — 2026-11-26.

Раздел «Навыки / Skills» показывает технологии и инженерные практики, с которыми работали участники команды. В него вошли стек из резюме участника и инструменты фронтенда визитки.

Категории и навыки редактируются в [данных команды](../../frontend/data/team.ts). Названия технологий общие для двух языков. Для названий категорий и переводимых терминов указывают варианты RU и EN. Зависимости самой визитки перечислены в [технологическом стеке проекта](../tech-stack.md).
