# 0033. Сокращение карточек портфолио

Дата принятия — 2026-11-26.

Посетитель видит саму визитку на странице портфолио, поэтому её карточка содержит только тип работы, название, описание и ссылку на репозиторий. Кнопка «Подробнее» появляется у проектов, для которых автор заполнил разделы рассказа.

Карточка QA Tester Agent показывает ленту проверки и три раздела о подключении репозитория, работе со стеком проекта и использовании подписки. Это решение обновляет [первоначальный состав карточки агента](0032-qa-tester-agent.md).
