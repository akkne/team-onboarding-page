# 0003. Одна страница для сайта-визитки

Дата принятия — 2026-11-25.

**Контекст.** ТЗ допускает одну страницу с меню по разделам или несколько страниц. Команде нужен перечень макетов для дизайнера. В приложении уже есть два адреса для языковых версий.

**Решение.** Планируем одну страницу с шапкой, рассказом о команде, участниками, навыками, проектами и контактами в подвале. Для RU и EN используем одну композицию и существующие адреса. Меню ведёт к секциям.

**Последствия.** Дизайнер собирает [адаптивные макеты визитки](../screens.md) из [общих компонентов](../components.md). Карточки раскрывают сведения об участниках и проектах прямо на странице.
