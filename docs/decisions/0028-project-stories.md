# 0028. Раскрываемые рассказы о проектах

Дата принятия — 2026-11-26.

В портфолио посетитель выбирает работу по краткому описанию. Чтобы он мог изучить проект на месте, каждая карточка раскрывается нативным элементом `details` с кнопкой `summary`. Это сохраняет управление с клавиатуры и работу без JavaScript. Ссылка на репозиторий доступна в обоих состояниях.

Внутри карточки показываем снимок главной страницы и рассказ команды о задаче, устройстве и результате. Для визитки используем снимок выбранной локали, для Dobropay — русскоязычный оригинал. Переводы рассказов и описаний изображений храним вместе с [данными проектов](../../frontend/data/team.ts). Устройство Dobropay сверено с презентацией команды и [репозиторием платёжной песочницы](https://github.com/akkne/dobropay).
