# 0006. Синяя палитра визитки

Дата принятия — 2026-11-25. Заменено [решением 0007](0007-solana-inspired-design.md).

По запросу команды внешний фон визитки стал синим. Содержимое лежит на отдельной поверхности, чтобы длинные тексты и карточки оставались читаемыми. Шапка, ссылки и выбранный язык используют акценты из темы Astryx. Системная тёмная тема использует собственные значения тех же токенов.
