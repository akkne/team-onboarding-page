# 0006. Синяя палитра визитки

Дата принятия — 2026-11-25.

По запросу команды внешний фон визитки стал синим. Содержимое лежит на отдельной поверхности, чтобы длинные тексты и карточки оставались читаемыми. Шапка, ссылки и выбранный язык используют акценты из [темы Astryx](../../frontend/themes/recessed-maxilla/theme.ts). Системная тёмная тема использует собственные значения тех же токенов.
