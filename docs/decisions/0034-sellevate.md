# 0034. Проект Артемия в портфолио

Дата принятия — 2026-11-26.

Sellevate занимает четвёртое место в портфолио. Карточка указывает роль Артемия Стёпкина как сооснователя и технического руководителя. Описание связывает задачу руководителя отдела продаж с работой голосового тренажёра и обменом событиями между микросервисами. Состав сервисов и обязанности шлюза описаны в [архитектуре Sellevate](https://github.com/akkne/sellevate/blob/990348e2eee38772d5f8f6ee97fad919902aa66c/docs/architecture.md), речевые адаптеры перечислены в [каталоге интеграций](https://github.com/akkne/sellevate/tree/990348e2eee38772d5f8f6ee97fad919902aa66c/docs/integrations).

Обе языковые версии показывают [снимок интерфейса](../../frontend/app/assets/projects/sellevate.webp), сделанный при локальном запуске [публичной страницы продукта](https://github.com/akkne/sellevate/blob/990348e2eee38772d5f8f6ee97fad919902aa66c/frontend/app/landing/page.tsx).
