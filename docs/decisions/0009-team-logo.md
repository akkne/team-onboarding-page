# 0009. Логотип команды в шапке и портфолио

Дата принятия — 2026-11-26.

**Контекст.** Команда передала логотип с двумя красными профилями для замены монограммы на сайте.

**Решение.** В шапке рядом с `rm.team` и на обложках проектов показываем оба профиля целиком. [Компонент эмблемы](../../frontend/components/team-emblem.tsx) использует один [исходный PNG](../../frontend/assets/logo.png). Next.js подбирает размер изображения для каждого места.

**Последствия.** Замена файла обновляет логотип в обеих языковых версиях. Ссылка в шапке сохраняет доступное имя команды, а декоративные изображения имеют пустой альтернативный текст. Размещение описано в [визуальной спецификации](../design.md).
