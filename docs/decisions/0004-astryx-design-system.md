# 0004. Использование дизайн-системы Astryx для сайта-визитки

Дата принятия — 2026-11-25.

**Контекст.** Для сборки одностраничного сайта-визитки команды recessed maxilla team ([карта экранов](../screens.md), [ведомость компонентов](../components.md)) нужна готовая дизайн-система, совместимая с Next.js 16 (App Router), React 19, TypeScript 5, Tailwind CSS 4, системными светлой/тёмной темами и работой базовых сценариев без JavaScript.

**Решение.** Взять за основу дизайн-систему **Astryx** (`@astryxdesign/core`) в режиме предсобранных стилей (pre-built dist, без StyleX build-плагина) вместе с мостом `@astryxdesign/core/tailwind-theme.css` и кастомной предсобранной темой `recessedMaxillaTheme` на базе `neutralTheme`. Сохранить фирменную палитру проекта (`#f5f6ed` / `#183f34` и `#142620` / `#e3eedf`) и системный шрифт без засечек для полной поддержки кириллицы и латиницы. Недостающие и специфичные для требований проекта элементы (эмблема, zero-JS переключатель языка, переносящаяся на 360 px шапка с якорным меню, семантические секции и доменные карточки) реализовать поверх примитивов и токенов Astryx.

**Последствия.** Полная схема интеграции, маппинг компонентов, перечень доработок и дизайн-токены зафиксированы в [спецификации адаптации Astryx](../design.md). Внедрение не требует перестройки сборщика Next.js/PostCSS; обновляется [карта документации](../README.md) и [описание дизайн-системы](../design-system.md).
