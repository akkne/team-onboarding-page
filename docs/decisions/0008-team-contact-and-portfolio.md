# 0008. Общий контакт и первая работа в портфолио

Дата принятия — 2026-11-25.

Для обязательных разделов отбора используем существующий публичный канал GitHub Issues и реализованную двуязычную визитку. В карточке без личного адреса ссылка явно обозначает обращение через команду. Команда может заменить общий адрес или заполнить личные ссылки в [файле данных](../../frontend/data/team.ts). Это дополняет [решение о публикации данных](0005-team-content.md).
