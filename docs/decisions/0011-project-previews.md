# 0011. Визуальные обложки проектов и фирменный знак Dobropay

Дата принятия — 2026-11-26.

**Контекст.** Обложки портфолио показывали одну и ту же монограмму, поэтому проекты не отличались визуально. Текстовая ссылка под описанием не выделялась как действие.

**Решение.** Использовать снимок сайта команды для первой карточки и снимок кабинета для Dobropay. Поверх изображения Dobropay показывать фирменный знак и строчное написание `dobropay` с цветами сайта (`#09318D`, `#F59ACC`) и его системным шрифтовым стеком. Ссылки проекта оформлять классом `.pill`; для изображений указывать описания на русском и английском.

**Последствия.** Превью лежат в `frontend/public/project-previews/` и поставляются вместе с сайтом. Сведения о раскладке карточек и их интерактивных состояниях внесены в [визуальную спецификацию](../design.md), [список компонентов](../components.md) и [дизайн-систему](../design-system.md).
