# 0035. Логотип на вкладке браузера

Дата принятия — 2026-11-26.

**Контекст.** В шапке визитки уже есть [логотип команды](../../frontend/assets/logo.png). Для вкладки браузера нужна его компактная версия.

**Решение.** Поместить [иконку 64 × 64 px](../../frontend/app/icon.png) в корень App Router. Оба профиля помещаются на белом квадратном фоне с сохранением пропорций.

**Последствия.** Next.js добавляет иконку к страницам обоих языков. При замене логотипа нужно обновить и его уменьшенную копию.
