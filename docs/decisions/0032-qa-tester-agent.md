# 0032. Карточка QA Tester Agent

Дата принятия — 2026-11-26.

Третья карточка портфолио описывает путь от отправки кода до публикации тестов и отчёта в отдельной ветке. Описание учитывает однократную настройку репозитория, подбор инструментов под стек и лимиты подписки. Источники описывают [этапы проверки](https://github.com/akkne/qa-tester-agent/blob/7166eef0ee71836dbf319cbd474ccf29a4823df7/docs/flows/push-to-report.md), [работу с разными стеками](https://github.com/akkne/qa-tester-agent/blob/7166eef0ee71836dbf319cbd474ccf29a4823df7/docs/agent-test-execution.md) и [вход через Codex CLI](https://github.com/akkne/qa-tester-agent/blob/7166eef0ee71836dbf319cbd474ccf29a4823df7/docs/codex-exec.md).

Два снимка из презентации команды показывают один запуск. [Лента](../../frontend/app/assets/projects/qa-agent-activity.webp) показывает начало работы с пятью изменёнными файлами. [Результат](../../frontend/app/assets/projects/qa-agent-result.webp) фиксирует два новых теста, 663 пройденных теста и длительность 150,7 секунды. Карточка показывает каждый снимок рядом с соответствующим этапом. Русская и английская версии используют оригинальные изображения с подписями для экранного диктора на языке страницы.
