# 0018. Четыре группы навыков команды

Дата принятия — 2026-11-26.

Чтобы список было проще просматривать, раздел «Навыки / Skills» объединяет технологии в четыре группы. Frontend включает Node.js и инструменты сборки интерфейса. Backend охватывает серверную разработку, базы данных, интеграции и модульные тесты. Architecture объединяет архитектурные подходы. Infrastructure включает эксплуатацию, наблюдаемость и Git.

Названия групп и навыков заданы на английском и совпадают на обеих версиях визитки. Раздел и сфера используют единый [список навыков](../../frontend/data/team.ts). Это уточняет [решение о навыках команды](0012-team-technology-skills.md) и [правило подписей сферы](0014-sphere-rendering-and-skills.md).
