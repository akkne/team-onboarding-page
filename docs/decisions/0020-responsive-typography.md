# 0020. Адаптивная типографика главной страницы

Дата принятия 26 ноября 2026 года.

**Контекст.** Прописные моноширинные подписи события и раздела «О команде» занимали много места из-за широких межбуквенных интервалов.

**Решение.** На обеих языковых версиях использовать общую адаптивную шкалу заголовков и подписей. Для коротких подписей сохранить регистр текста, использовать пропорциональный шрифт среднего начертания и убрать декоративные чёрточки. Размеры и интервалы заданы в [общих стилях](../../frontend/app/globals.css).

**Последствия.** На устройстве без ABC Diatype браузер выбирает Helvetica, Arial или системный гротеск. Для поставки ABC Diatype всем посетителям потребуется веб-лицензия проекта. [Условия Dinamo](https://abcdinamo.com/licenses) · [Визуальная спецификация](../design.md)
