# 0015. Удаление ссылок из карточек участников

Дата принятия — 2026-11-26.

**Контекст.** В каждой карточке участника показывалась ссылка в общий GitHub Issues команды. Эти ссылки визуально выглядели как отдельные кнопки и отвлекали от информации о людях.

**Решение.** Удалить ссылки из карточек участников на русском и английском, сохранив контакт команды в подвале. Убрать также неиспользуемое поле личного контакта участника.

**Последствия.** Карточки участников показывают только сведения об участниках, а общий канал связи остаётся в подвале. Это отражено в [описании компонентов](../components.md) и [README](../../README.md).
