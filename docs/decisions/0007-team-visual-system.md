# 0007. Визуальная система визитки

Дата принятия — 2026-11-25.

Команда запросила полный редизайн визитки с сохранением обязательных разделов отбора. Вместо темы Astryx вводим локальные токены Tailwind CSS, статический первый экран с авторской графикой и карточки на семантической разметке. Шрифт и изображение входят в сборку. Обе локали используют общий макет.

Решение заменяет [интеграцию Astryx](0004-astryx-design-system.md) и [синюю палитру](0006-blue-palette.md). Размеры, состояния и соответствие компонентов зафиксированы в [спецификации](../design.md).
