# 0010. Сфера из частиц на первом экране

Дата принятия — 2026-11-26.

Команда выбрала вращающуюся сферу из частиц для первого экрана. Название команды, событие, девиз и переход к участникам сохраняются.

Клиентский компонент проецирует вращающееся облако точек на Canvas 2D. Сцена рисуется локально средствами браузера. Вне видимой области и в фоновой вкладке анимация приостанавливается. При уменьшенном движении сфера остаётся неподвижной. До первого кадра виден локальный WebP.

Подписи на поверхности берутся из отдельного [списка переводов](../../frontend/data/sphere-labels.ts). Пустой список оставляет сферу без подписей. Решение обновляет оформление первого экрана из [решения 0007](0007-team-visual-system.md).
