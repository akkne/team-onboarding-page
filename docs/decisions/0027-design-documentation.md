# 0027. Описание визуальной системы визитки

Дата принятия — 2026-11-26.

В [визуальной спецификации](../design.md) и журнале решений описываем оформление через свойства самой визитки — размеры заголовков, расположение элементов и поведение сферы. Для подписей события, раздела и категорий в обеих локалях используем класс `.section-label`. Его начертание и размеры заданы в [общей таблице стилей](../../frontend/app/globals.css).
