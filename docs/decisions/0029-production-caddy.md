# 0029. Публикация визитки через Caddy

Дата принятия — 2026-11-26.

**Контекст.** Для домена recessed-maxilla.space нужны публичный HTTPS и выкладка на сервер с объёмом памяти меньше 1 ГБ.

**Решение.** Выкладывать образ Next.js под Linux amd64 с тегом, соответствующим версии исходного кода. Образ можно собрать на рабочей машине либо на сервере с дополнительной памятью для сборки. Caddy обслуживает домен, управляет сертификатом и передаёт запросы контейнеру через локальный порт.

**Последствия.** Версию приложения можно восстановить из сохранённого образа по тегу. Для выпуска сертификата DNS домена должен указывать на сервер. [Инструкция по выкладке](../../infra/production/README.md)
