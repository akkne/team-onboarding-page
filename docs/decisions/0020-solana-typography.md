# 0020. Типографика главной страницы Solana

Дата принятия 26 ноября 2026 года.

**Контекст.** Моноширинные прописные и широкие интервалы в подписях события и раздела «О команде» расходились с выбранным референсом.

**Решение.** Применить на обеих языковых версиях адаптивные размеры, высоту строки, насыщенность и межбуквенный интервал из стилей Solana. Для подписей взять стиль названия баннера, сохранить регистр текста и убрать декоративные чёрточки. В CSS первым указать ABC Diatype, затем системные гарнитуры из стека Solana. [Шкала Solana](https://github.com/solana-foundation/solana-com/blob/a0c373ea99eea6614c632a43e0919d62d2748c04/apps/web/src/app/globals.css) · [Первый экран и баннер](https://github.com/solana-foundation/solana-com/blob/a0c373ea99eea6614c632a43e0919d62d2748c04/apps/web/src/components/index/hero.tsx)

**Последствия.** На устройстве без ABC Diatype браузер выбирает Helvetica, Arial или системный гротеск. Для поставки ABC Diatype всем посетителям потребуется веб-лицензия проекта. [Условия Dinamo](https://abcdinamo.com/licenses) · [Визуальная спецификация](../design.md)
