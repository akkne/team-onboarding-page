# 0021. Роли и достижения в карточках участников

Дата принятия — 2026-11-26.

В каждой карточке под именем указаны роли участника на английском. Далее коротким списком приведены опыт и награды на языке страницы. Для олимпиад указаны результат и трек, для диплома за проект — степень, конференция, год и тема работы.

Достижения редактируются по одному в [данных участников](../../frontend/data/team.ts). Сведения о личном вкладе в проект ведутся в [README](../../README.md).
