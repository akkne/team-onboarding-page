# 0038. Сфера по центру первого экрана

Дата принятия — 2026-11-26.

Центр холста и статичного изображения совмещён с центром секции по обеим осям при любой ширине окна. На экранах уже 1024 CSS-пикселей название команды размещается выше центра, а девиз и кнопка перехода к участникам — ниже. Так середина сферы доступна для перетаскивания.

Решение обновляет расположение сферы из [записи 0013](0013-hero-layout-and-motion.md).
