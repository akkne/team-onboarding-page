# Архитектура recessed maxilla team

Next.js App Router генерирует две версии визитки при сборке. Правило в `frontend/next.config.ts` перенаправляет посетителя с `/` на `/ru`.

Сегмент `frontend/app/[lang]/` задаёт язык HTML-документа и выводит визитку по структурированным данным из [team.ts](../frontend/data/team.ts). Переключатель ведёт на адрес выбранного языка и работает с клавиатуры и при отключённом JavaScript. Обе версии используют [общие стили](design-system.md).

Серверные компоненты формируют HTML обеих страниц при сборке. Tailwind CSS задаёт общую тему. Next.js включает локальные Inter и WebP в статические ресурсы приложения. На первом экране клиентский компонент рисует сферу в Canvas 2D. Текст и ссылки доступны в статическом HTML.
