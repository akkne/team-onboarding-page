# Архитектура recessed maxilla team

Next.js App Router генерирует две версии визитки при сборке. Правило в `frontend/next.config.ts` перенаправляет посетителя с `/` на `/ru`.

Сегмент `frontend/app/[lang]/` задаёт язык HTML-документа и выводит визитку по структурированным данным из [team.ts](../frontend/data/team.ts). Переключатель ведёт на адрес выбранного языка и работает с клавиатуры и при отключённом JavaScript. Обе версии используют [общие стили](design-system.md).

Серверные компоненты формируют HTML обеих страниц при сборке. Tailwind CSS задаёт общую тему. Браузер выбирает гарнитуру из системного стека в CSS. Next.js включает изображения в статические ресурсы приложения. На первом экране клиентский компонент рисует сферу в Canvas 2D. Текст и ссылки доступны в статическом HTML.

На сервере Caddy завершает TLS для recessed-maxilla.space и передаёт запросы Next.js через порт контейнера, привязанный к loopback. [Схема запуска и выкладка](../infra/production/README.md)
