# Архитектура Team Onboarding

Next.js App Router генерирует две версии стартовой страницы при сборке. Правило в `frontend/next.config.ts` перенаправляет посетителя с `/` на `/ru`.

Сегмент `frontend/app/[lang]/` задаёт язык HTML-документа и выводит приветствие из словаря страницы. Переключатель ведёт на адрес выбранного языка и работает с клавиатуры и при отключённом JavaScript. Обе версии используют [общие стили](design-system.md).
