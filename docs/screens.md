# Карта экранов

Корневой адрес перенаправляет на `/ru`. Русская и английская (`/en`) версии имеют одинаковую последовательность разделов. Переключатель языков доступен в шапке.

| Раздел | Действие посетителя |
| --- | --- |
| Шапка и первый экран | Узнать название и девиз, выбрать язык, перейти по меню или кнопке к участникам |
| О команде / About us | Прочитать, кто участвует и почему команда пришла на хакатон |
| Участники / Members | Посмотреть роли, группу, достижения и навыки каждого участника |
| Навыки / Skills | Найти языки, технологии и инструменты по категориям |
| Проекты / Projects | Прочитать о выполненной работе или идее, открыть доступный проект |
| Контакты / Contact | Написать команде через Issues или открыть репозиторий |

Меню отображает пункт портфолио при наличии хотя бы одной работы. Сетка карточек меняется с одной колонки на две и четыре. В подвале ссылки переносятся по доступной ширине. Пропорции, интервалы и поведение на телефоне описаны в [визуальной спецификации](design.md), состояния элементов — в [ведомости компонентов](components.md).
