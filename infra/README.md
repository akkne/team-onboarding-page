# Docker и локальная выкладка

В корне проекта выполните

```sh
docker compose config --quiet
docker compose up -d --build frontend
```

Откройте [recessed maxilla team](http://localhost:3000). Для выбора другого локального порта скопируйте `.env.example` в `.env` и измените `FRONTEND_PORT`. Контейнер запускает результат standalone-сборки на порту 3000.

После слияния обновите локальную ветку `main`. Команда `docker compose ps --status running --services` показывает запущенные сервисы. Для работающего `frontend` повторите команду сборки и запуска. Если экземпляр запущен напрямую, обновите его тем же способом. Если приложение остановлено, пропустите выкладку. После обновления откройте страницу и проверьте переход RU → EN → RU.
